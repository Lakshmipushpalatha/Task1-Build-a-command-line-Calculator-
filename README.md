Command-Line Calculator in Java

About the Project

This project is a simple command-line calculator developed using Java. It performs basic mathematical operations based on the user's choice.

Features

- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- Modulus (%)
- Handles division by zero.
- Handles invalid numeric input.
- Uses separate methods for each arithmetic operation.

Technologies Used

- Java
- Scanner class for user input
- Switch statement for operation selection
- User-defined methods

How to Run the Program

1. Install the Java Development Kit (JDK).

2. Save the source code as "Task1.java".

3. Open a terminal in the folder containing the file.

4. Compile the program:
   
   javac Task1.java

5. Run the program:
   
   java Task1

Sample Output

Enter first number: 10
Enter second number: 4

Choose an operation:
1. Addition (+)
2. Subtraction (-)
3. Multiplication (*)
4. Division (/)
5. Modulus (%)
Enter your choice: 1
Result: 14.0

Error Handling

The program checks for invalid numeric input and prevents division or modulus by zero. It also displays an error message when the user selects an invalid operation.

Learning Outcomes

- Taking input using Scanner
- Using switch statements and if conditions
- Creating and calling methods
- Handling invalid input and arithmetic errors
